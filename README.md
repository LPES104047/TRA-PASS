## 功能總覽

**班次查詢** — 選擇出發站與目的站，系統從靜態班表中篩選方向正確的列車，依當前台灣時間排列尚未出發的班次，支援跨午夜班次的日期邊界處理與明日班次切換。

**即時誤點** — 啟動連線後，定時取得 TDX 全台即時動態（LiveBoard），將各列車的誤點分鐘數疊加至預計發車時間上。

**班次詳情** — 點選任一班次展開 Modal，顯示完整停靠站與各站到發時間，標示出發站與目的站位置。

**維修車庫** — 深夜或查詢無結果時，顯示以純 SVG 繪製的列車停放動畫（EMU3000、EMU800、太魯閣號等車型）。

## 即時連線控制

連線按鈕左側帶有呼吸燈圓點，透過顏色與脈動頻率反映當前連線狀態：

| 燈號 | 狀態 | 說明 |
|:----:|------|------|
| ⚫ | **離線** | 未啟用即時連線，僅讀取靜態班表 |
| 🟡 | **同步中** | 正在向後端發送請求、等待回應 |
| 🟢 | **連線正常** | 已取得即時誤點資料，顯示連線剩餘時間與下次更新倒數 |
| 🟠 | **暫無資料** | 連線成功但 TDX 當前未回傳該站誤點資訊 |
| 🔴 | **連線異常** | 請求失敗，進入 60 秒避讓期後自動重試 |

> 按下連線按鈕後會啟動一個 **5 分鐘的連線時限**，時間到自動斷線，避免長時間佔用 API 配額。

## 前端防護機制

為防止使用者（或多開分頁）對後端造成過量請求，前端實作了多層速率控制：

```
使用者操作
    │
    ▼
┌─────────────────────────┐
│  20 秒全域跨分頁鎖       │  ← 任一分頁發出請求後，所有分頁共用冷卻
│  (localStorage 時間戳)   │
└────────────┬────────────┘
             │ 冷卻結束
             ▼
┌─────────────────────────┐
│  180 秒常規快取          │  ← 非手動強制更新時，直接回傳快取資料
└────────────┬────────────┘
             │ 手動觸發
             ▼
┌─────────────────────────┐
│  手動更新冷卻 20 秒       │  ← 按鈕鎖定，防止連擊
└────────────┬────────────┘
             │ 若發生錯誤
             ▼
┌─────────────────────────┐
│  網路錯誤退避 60 秒       │  ← 停止一切請求，防止錯誤風暴
└─────────────────────────┘
```

## 絕對時鐘校準

瀏覽器在背景分頁閒置或系統休眠時，會將 `setTimeout` / `setInterval` 大幅降頻（如閒置 5 分鐘後限制為每分鐘僅觸發一次）甚至完全凍結執行，導致傳統的相對計時器（如 `count--`）在切回畫面時出現大幅偏移。

本專案的中央計時器改以 **絕對時間戳** 運作：

1. 所有到期時間皆以 `Date.now() + N * 1000` 的形式寫入 `localStorage`
2. 每秒 tick 時，計算 `Math.ceil((到期時間戳 - Date.now()) / 1000)` 得出剩餘秒數
3. 無論分頁休眠多久，切回後的第一次 tick 即可算出正確的剩餘時間

這確保了全域冷卻鎖、連線時限倒數、自動更新倒數在任何情境下的時間精度。

## 後端 API 設計（`/api/trains`）

| 層級 | 機制 | 說明 |
|:----:|------|------|
| 1 | 來源驗證 | 正式環境驗證 Host / Referer，非白名單來源回傳 `403` |
| 2 | 20 秒絕對冷卻 | 快取建立後 20 秒內，無論參數為何一律回傳快取 |
| 3 | 180 秒常規快取 | 未帶 bypass 參數時，3 分鐘內持續回傳快取 |
| 4 | Promise 鎖 | 多請求同時湧入時只發出一次 TDX 請求，防止快取擊穿 |
| 5 | Token 快取 | 記憶體中快取 Token，過期前 60 秒刷新；收到 401 自動重取 |
| 6 | 強制超時 | TDX 請求 8 秒、Token 請求 5 秒，逾時自動中斷 |
| 7 | 故障墊檔 | TDX 異常時回傳上一輪的快取資料，避免前端白屏 |

## 本地執行

```bash
npm install
npm run dev
```

開啟 [http://localhost:3000](http://localhost:3000) 即可使用。

## 部署

支援 Vercel 與 Firebase App Hosting（已配置 `manifest.json` 供 PWA 安裝）。

部署時需設定 TDX API 憑證的環境變數。若使用自訂網域，需將該 host 加入 API 路由的白名單（可透過環境變數設定）。
